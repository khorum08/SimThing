## BUILD

This is the final implementation rung of the 15.5-15.7 remediation arc. 15.5 separated spatial and temporal recursion; 15.6 homed that corrected operator onto the real session RF arena. 15.7 must now consume the 14.0 execution-authority design for the actual runtime lifetime instead of creating authority at admission and dropping the borrowed capsule immediately afterward.

The live runtime/session owns one opaque execution lease. That lease is the execution-lifetime capability; borrowed `TreeExecutionAuthority`/context/binding views may be created transiently from it but may not themselves become durable public authority. Recreate/restore/migration of the SAME durable execution retains the persisted realm and mints a new incarnation. A semantic fork is a different execution and therefore mints a new realm. No process-global writer registry is permitted.

Fresh identity semantics are strict. Ordinary `open`/new always creates a NEW realm, even for byte-identical scenario/spec content. Same-realm continuation is only the explicit restore/reopen API, which carries a persisted execution-identity record containing the durable realm source of truth. The double-open witness must prove identical fresh opens do not collide. Content hashes, deterministic default realms, paths, or reconstructed hashes are not durable identity.

`TreeGenerationPermit(N)` is one-use authority for one WHOLE tree-generation. Generation N consumes exactly one permit while executing every same-generation spatial edge, sealing its products, and preparing temporal demand for N+1. It is not an edge permit. The permit cannot be reused or applied to another generation; N+1 economic execution requires its own N+1 permit. Failures must not partially advance an unauthorized tree-generation.

Qualification must bind the COMPLETE semantic kernel bundle. Child-share EML/ISA, the 15.2 persistence transform shader/program, the exact projection ABI, and the planner code that constructs executable RF AccumulatorOp upsweep/downsweep/order-band sequences are all semantic executable law. The fingerprint therefore carries build-time provenance for the complete relevant production implementation, or an equivalent semantic-plan implementation digest. Runtime `rustc -Vv` or other compiler probing is not authority and must disappear from production runtime code.

The final referee must prove that this lifetime authority layer does not perturb the already-graduated economic object: the 15.6 real-arena substrate, E5 exact-basis law, E6 work-conserving/commitment law, and the full 15.5 cross-product must execute under the lease/permit lifecycle with CPU/resident parity and unchanged authority census.
