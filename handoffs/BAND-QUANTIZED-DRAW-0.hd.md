## BUILD
- **(a) Restore the CostBand.** A band whose threshold is a unit cost yields `N = floor(V/C)`, `R = V - N*C`, so `V = N*C + R` **exactly** — a conservative quantization losing nothing. Both operands are ALREADY sealed on `BandCrossingDelta` (`threshold()`, `post_value()`): the quotient needs no kernel widening and zero WGSL diff. The multiply is authored and upstream; the divide is downstream of allocation. Restores the orphaned `throttle_hint_max_per_tick` as `min(floor(V/C), throttle_hint_max_per_tick)` — authored, hydrated and stored today, with its own comment saying it is not enforced.
- **CostBand is THE sink definition, not a mode.** Observation is the BASE CASE — a crossing costs and consumes nothing, and that already IS observation; **action is observation with a CostBand attached**. The authored question is *"is this a sink?"*, never *"is this a CostBand?"*. **Booleans are depth 1**, which REMOVES a branch rather than adding a case — the move that made `unowned` a real owner rather than `None`. **Marker is AUTHORED per registration** (may also be per resource; per-registration wins; ambiguity is an admission error), riding the existing CPU-side semantic table indexed by `event_kind`, never the GPU POD.
- **(b) Join `TransformOp` to the EML ISA.** `Add`/`Multiply` are already `EML_OP_ADD`/`EML_OP_MUL` and `Set` is `LITERAL_F32` ignoring the current value — but the two are still SEPARATE paths. Join them: a static value becomes the one-node program `LITERAL_F32(v)`; magnitude bands become `SELECT(CMP_GE(N,t2), hi, SELECT(CMP_GE(N,t1), mid, lo))`; `N` arrives via `EML_OP_PARAM`. **The opcodes already exist** — re-expression, not language design.
- **ClauseScript surface:** the queue's EXISTENCE and SHAPE are authored; its DEPTH is runtime state. Queueing builds mutates a property value and MUST NOT require re-hydration.
## FENCES
- **Conservation is PER-RESOURCE-CHANNEL, never across the transformation.** `N*C` of the input is consumed exactly; `N*coefficient` of the output is MINTED. 8.1 must not judge across a recipe or every legitimate build reads as a violation.
- **Unbounded remainder is the starvation failure** — a queue perpetually under one unit's cost accumulates forever; the remainder needs an authored horizon. A "permanent" growth queue is `UntilDissolved` + `AtSessionEnd`, never a permanence variant. **"Which cohorts grow first" is CONTENTION**, resolved by an authored rule at 8.2, never vector iteration order.
