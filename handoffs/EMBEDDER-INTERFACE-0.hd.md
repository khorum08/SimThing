## BUILD
- Formalize the existing SimThing embedding surface as exactly five verbs: **Derive, Populate, Overlay, Bind, Run**. Keep the surface human-readable and scale-invariant; one SimThing and a tree of thousands use the same verbs.
- Land `simthing-embedder` only as a stateless leaf facade. Pure/read-only queries needed to expose already-landed data may be added in the owning engine crate; the facade itself remembers and decides nothing.
- Derive carries specialist/owner-seat data and the sanctioned owner x specialization query; Populate builds/adopts the tree, binds inherited ownership, and declares queue shape; Overlay requires authored origin+horizon; Bind exposes sealed event bindings plus read-only generation-coherent shadow observation; Run selects paced|continuous posture over one kernel and one replay history.

- This rung is interface formalization, not implementation of new simulation capability. No guide/exemplars (11.2), convergence witness (11.3), portability proof/canonization (12.x), StemThing-B, Vector CostBand, or ClauseThing debt repair.
- ClauseThing remains one optional front-end; no domain vocabulary or reverse dependency may cross back through the Vendor Door.
