## BUILD
15.10 closes one constitutional lifetime hole: **one pass per generation means an aborted generation may be retried only when no economic side effect has occurred, unless complete rollback is actually proven.**

Stamped source currently has only `live_generation` plus `generation_permit_outstanding` on the private tree execution seal. `TreeGenerationPermit::Drop` clears the outstanding bit whenever the permit is unconsumed. Ordinary `SimSession` mints the permit before boundary work and calls `finish_generation` only after boundary/economy processing. The resident executor validates that permit before reserving resident schedule rows, encoding/submitting exact GPU work, and appending the immutable live head. Therefore the falsifier target is concrete: post-dispatch failure can leave economic effects behind while Drop makes a same-generation permit mintable again.

**FALSIFIER FIRST.** Use the actual ordinary session and prove the current result before changing production. A direct `ResidentClearingRuntime` harness, manually forged permit, CPU-only oracle, or synthetic settlement path does not discharge the rung. The first attempt must prove real resident economic work happened; the induced failure must occur before the session consumes the permit at `finish_generation`; the second call must target the same session and generation.

After the RED, adjudicate the only two allowed outcomes from the ladder. If the implementation already rolls back every effect, prove that comprehensively and make no poison mechanism. Otherwise implement the expected fail-stop shape as the narrowest extension of the existing authority seal. The authority must distinguish **untouched** from **touched** before Drop decides retryability. Touching is authorization state, not a post-hoc observation: transition before the first side effect that is not proven rollback-safe. Untouched Drop releases the outstanding permit exactly as today. Touched abort poisons the current generation. A faulted generation rejects retry before economics; successful `finish_generation` remains the sole N->N+1 commit and resets the next generation to clean state. Do not add an in-rung recovery API.

The state belongs to the one private realm/incarnation/generation seal already retained by `TreeExecutionLease`; no scenario semantic state, global registry, process lock, host retry coordinator, or second runtime authority is permitted. Existing wrong/reused/foreign/stale/duplicate permit guards remain authoritative.

If the remedy changes any source already in the E8 semantic bundle (`session.rs`, `resident_clearing_runtime.rs`, `growth_entitlement.rs`, etc.), the fixed production qualification must fail closed until requalified. The only admitted companion is the already-established two-literal mechanism: old-pin refusal -> actual observed replacement -> identical production/referee literals, no design widening.
