## 0. Executive disposition

Fable's review approves the revised ActionBand design as a **real re-derivation**, not a naming patch.
The semantic conclusion stands:

```text
STEAD      = non-conserved propagated state / influence
PALMA      = min-plus potential / impedance / lawful local descent
Gu-Yang    = conserved saturating flux / realizable channel throughput
RF         = conserved claims / clearing / disbursement / channel identity
CostBand   = exact sink/work quantization
ActionBand = unresolved-target lifecycle consuming those native authorities
Overlay    = actuation / deformation emitted back into ordinary SimThing state
```

The Gu-Yang omission was load-bearing because PALMA answers direction/potential and CostBand answers
sink price, while neither answers how much conserved quantity may actually traverse a constrained
channel this generation or where it saturates. Gu-Yang already owns that answer. ActionBand must
**consume native Gu-Yang/RF outputs, never reconstruct a private throughput model.**

Fable specifically approved:

- §17.24 `Field-Triad Native Progress Law`;
- F15, which treats a required private ActionBand flux model as a substrate/premise falsifier;
- the decision that Gu-Yang adds **band/progress observables, not a target form**;
- direct reuse of already-hot Gu-Yang outputs as the optimized path;
- additive remedial 7.* rungs by default, with reopening only if archaeology proves unavoidable; and
- supersession of the former §18.7 semantic fence, leaving ABI/fusion/performance and navigation
  physics fenced rather than Gu-Yang ownership.

The Owner adds one sequencing/design directive beyond Fable's two-rung proposal:

> **Do not reopen the already-vendorized movement rung merely to retrofit Gu-Yang. Add a new,
> explicit Full-Field-Triad vendorized movement rung that proves the complete modern movement model
> from the intrinsic ActionBand/RF/Overlay substrate.**

This preserves the earlier rung as historical evidence while making the corrected complete model a
new positive proof.

## 2. Fable refinements to bind at rung mint

### 2.1 Bounded-feedback admission on field-seeded emissions

The loop

```text
ActionBand pressure
    ↓
RF claim / field demand
    ↓
Gu-Yang sweep
    ↓
saturation / stall
    ↓
ActionBand observes result
    ↓
next-generation emission
```

is a recurrent feedback loop. Generation pacing bounds update **rate**, not feedback **gain**. An
unbounded authored rule such as `demand += k * stall` may form a positive-feedback amplifier.

Any ActionBand emission binding that writes into a lane which seeds a field/RF recurrence must be
admitted under the existing bounded-feedback contract: finite decay where persistence is used,
explicit bounds/clamps, and no admitted positive unbounded recurrence. This is a reuse of existing
EML/gadget admission law, not a new controller subsystem.

### 2.2 Signed opposed-demand witness

A capacity monotonicity test proves magnitude but not direction. Gu-Yang conservative flux is signed
with respect to canonical edge orientation / target-relative progress. The remedial proof must include
symmetric opposed demand on one channel.

Required invariant:

> **Symmetric opposed demand produces mutual stall/contest, not mutual positive ActionBand progress.**

A lowering that uses `abs(flux)` as target progress must RED. The ActionBand binding must consume
flux projected toward its target/authorized direction while preserving the native canonical Gu-Yang
sign/order authority.

### 2.3 Gu-Yang is instantaneous; persistence is authored state

Fold this sentence into the ActionBand authority discussion (recommended §12.2) when the DA performs
anchor co-evolution:

> **Gu-Yang remains the instantaneous conservative mechanism. Persistence of saturation/stall is
> authored ordinary state (for example admitted decay-memory state) and never hidden history owned by
> Gu-Yang, ActionBand, or a saturation listener.**

This complements §17.21's previous-plane law and §17.19's single-crossing-surface law. A request for
"stall memory" therefore means an admitted state/overlay/property, not a new flux-history facility.

### 2.4 Per-binding conserved-progress bound source

The ActionBand document correctly refuses to canonize one universal formula such as
`min(RF_grant, flux_available, flux_realized)`. Different native lanes expose different already-resolved
authorities. That choice must not remain an implementation convention.

Each conserved-progress binding must declare exactly one authoritative bound source from a closed
admission vocabulary equivalent to:

```text
None
RfGrant
GuYangAvailable
GuYangRealized
```

The exact Rust spelling is rung-local; the closed semantics are binding.

Admission must reject:

- **double-bounding** — e.g. applying a Gu-Yang realized result and then multiplying/minimizing it
  against the same RF grant again when the realized value already includes that constraint;
- **zero-bounding / authority gap** — both RF and Gu-Yang assuming the other supplied the executable
  bound; and
- a vendor-local fifth source or implicit default invented outside the one ActionBand admission door.

This is an ActionBand **binding descriptor**, not a new resource taxonomy and not a target form.

### Proposed 7.5a — `ACTIONBAND-FIELD-TRIAD-PROGRESS-0`

**Purpose.** Bind generic ActionBand progress/band operands to existing STEAD/PALMA/Gu-Yang/RF
outputs as native GPU inputs, with no new field solve, crossing surface, target form, or throughput
model.

**Scope.**

- Admit resident STEAD/PALMA/Gu-Yang field outputs as ActionBand observables/bindings.
- Admit available flux, realized flux, saturation/stall magnitude, and already-sanctioned
  choke/contest projections as ordinary anchored operands.
- Add the direct resident-output fast path: where the exact authoritative field observable already
  exists, ActionBand binds to it rather than rerunning equivalent EML/field work.
- Add the closed per-binding conserved-progress bound-source declaration
  (`None | RfGrant | GuYangAvailable | GuYangRealized`, semantic vocabulary; exact code name rung-local).
- Apply the existing bounded-feedback admission contract to ActionBand emissions that feed a
  field-seeded/RF recurrence.
- Preserve Gu-Yang instantaneous semantics; no stall-history state is minted implicitly.
- Preserve §17.19 single crossing surface and §17.20 closed target forms.
- No local-minimum/adversarial navigation work.

**Exit proof.**

1. A synthetic conserved-channel ActionBand consumes a **real** Gu-Yang/
   `FieldSweepRegistration` output with zero ActionBand-local throughput solver.
2. Reducing admitted channel capacity reduces executable ActionBand progress while leaving target and
   ActionBand EML unchanged; restoring capacity restores progress.
3. The same workload using resident exact field output performs no duplicate field solve and no CPU
   numerical readback.
4. Each conserved progress leg has exactly one admitted bound source; planted double-bound and
   no-bound mutants fail admission or RED under a semantic equivalence witness.
5. A field-seeded positive unbounded feedback gadget fails bounded-feedback admission; a bounded/
   decaying equivalent admits.
6. Planted private-throughput/congestion/saturation implementation REDS against the native result.

### Proposed 7.5b — `ACTIONBAND-SPATIAL-FLUX-WITNESS-0`

**Purpose.** Prove the generic Field-Triad ActionBand binding over structural spatial adjacency without
making movement the source of the general mechanism.

**Scope.**

- Born-mortal/scenario-neutral spatial witness.
- STEAD/overlay state supplies local conditions.
- PALMA supplies the authoritative local potential/impedance direction where routing applies.
- Gu-Yang/RF supplies signed realizable conserved throughput/saturation on the capacity-bearing

- ActionBand binds those native values as progress/operands.

- No movement-local congestion model, planner, path/predecessor object, or saturation listener.
- Saturation does not authorize rerouting/search; §18 local-minimum/adversarial-navigation fence

**Exit proof.**

1. Same target and PALMA potential, different Gu-Yang channel capacity ⇒ same lawful descent identity
   but different per-generation executable progress.
2. Saturated capacity-bearing lane limits/stalls progress without changing target vocabulary or
   invoking a route-search mechanism.
3. **Opposed-demand witness:** equal opposed demand on one conservative channel produces mutual
   stall/contest. An `abs(flux)` mutant that advances both ActionBands REDS.
4. Canonical edge/order/sign authority comes from the admitted Gu-Yang registration; ActionBand
   cannot reorder or reinterpret it privately.
5. Removing the witness after proof removes no production ActionBand/Field-Triad capability.

**Owner addition.** Do **not** reopen 7.4 merely to retrofit Gu-Yang. Build a new vendorized movement
model that consumes the corrected complete intrinsic substrate.

**Purpose.** Prove the actual modern movement specialization as an ordinary derived ActionBand/
Overlay use of the **full Field Triad**, rather than preserving or mutating the historically graduated
PALMA+CostBand-only witness.

**Required model.**

```text

        ↓

        ↓
STEAD + overlays compose conditions / pressure / impedance inputs
        ↓

        ↓

        ↓

        ↓

        ↓

```

The human-readable vendor may call the resources `movement_points`, `fuel`, `lane_capacity`, etc.;
none of those names enter core numerical dispatch.

**Exit proof.**

1. A movement ActionBand reaches the same target using identical PALMA potential under two admitted
   lane capacities; route descent remains identical while per-generation physical movement differs
   exactly with native Gu-Yang/RF realizable throughput.
2. With symmetric opposed movers/pressure on a capacity-bearing lane, both do **not** advance merely
   because gross/absolute flux is high; the native signed/stall result governs progress.
3. Movement-point/fuel consumption is CostBand quantization downstream of the selected native
   progress/availability binding; CostBand is not used as lane-capacity authority.
4. Changing an ordinary overlay that changes field/RF conditions alters the resulting movement on the
   next lawful generation without invoking movement-specific path/congestion code.
5. Arrival dissolves/collapses the movement ActionBand/actuation state through ordinary lifecycle;
   no permanent task/movement executor state remains.
6. Delete/rename every human-readable movement designation in the CPU semantic shadow and the GPU
   numerical result remains bit-identical.
7. Grep/type proof: no peer `MovementPlanner`, path/predecessor object, congestion service,
   `FluxThing`, movement-specific saturation evaluator, or rival crossing machine becomes production
   authority.

**Why this is a separate rung from 7.5b.** 7.5b proves the **generic signed spatial flux binding** in a
born-mortal witness. 7.5c proves a real **vendorized domain composition** that exercises location
Property/velocity, target lifecycle, STEAD/overlay deformation, PALMA direction, Gu-Yang throughput,
RF, CostBand, and actuation together. The separation keeps movement from defining the generic law
while still demanding an end-to-end production-shaped proof before 8.x proceeds.
